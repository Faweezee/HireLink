# HireLink 💼

HireLink is a full-stack job board platform designed to connect job seekers with employers through a modern, responsive, and intuitive digital experience.

## Features
- User authentication (Job seekers & employers)
- Job posting and management
- Advanced job search and filtering
- Dashboard for applicants and recruiters
- Responsive PC design

## Tech Stack
### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- JavaScript


### Backend
- Node.js
- Express.js
- MongoDB
